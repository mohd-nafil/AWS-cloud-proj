# AWS EC2 Web Server Deployment & Monitoring

## 📌 Project Overview

This project demonstrates the deployment and basic administration of a Linux web server using AWS EC2 and Apache.

## 🎯 Objective

To deploy a web server on AWS EC2, configure network access, manage storage, and monitor the server.

## 🛠️ Technologies Used

* AWS EC2
* Ubuntu Linux
* Apache Web Server
* AWS Security Groups
* Amazon EBS
* Cloud watch monitoring
* SSH

## 🏗️ Architecture

Internet → Security Group → EC2 Ubuntu Server → Apache Web Server → Website

## 🔧 Implementation

1. Created an AWS EC2 Linux instance.
2. Configured Security Group rules for SSH and HTTP access.
3. Connected to the Linux server using SSH.
4. Installed and configured Apache Web Server.
5. Created and hosted a custom webpage.
6. Attached and managed an EBS volume.
7. Configured basic CloudWatch monitoring.

## 📸 Screenshots

Screenshots of the EC2 instance, Security Group, SSH connection, Apache server, webpage, EBS volume, and CloudWatch monitoring are included in this repository.

## ✅ Result

Successfully deployed and accessed a web server hosted on an AWS EC2 Linux instance.
